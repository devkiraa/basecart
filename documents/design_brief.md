# UI/UX Design Brief — Basecart

## 1. Visual Aesthetics Philosophy
The Basecart design language is focused on clean layout structures, premium typography metrics, high card contrast ratios, and glassmorphic header accents. It aims to present complex metrics concisely to admins while keeping storefront layouts minimal.

## 2. Color Palette System
* **Brand Colors**:
  - Indigo Primary: `#4F46E5` (Active actions, buttons)
  - Indigo Dark: `#4338CA` (Hover interactions)
  - Amber Accent: `#F59E0B` (Warning indicators, highlights)
* **Neutral Slate Stack**:
  - Card background surfaces: `#FFFFFF`
  - Platform workspace canvas: `#F8FAFC`
  - High-contrast body text: `#1F2937`
  - Muted descriptors: `#6B7280`

## 3. Typography Stack
* **Headers**: Outfit (Google Fonts) — loaded for premium geometric headings.
* **Body & Data**: Inter (Google Fonts) — loaded for readability in data tables, logs, and settings parameters.

## 4. UI Grid & Components
* **Layouts**: Flexbox and CSS Grid grids for responsiveness.
* **Micro-Animations**: Clean translation animations on hover states, pulsing green dots for live servers and database health.
* **Data Presentation**: Flat UI cards with light borders, replacing heavy container headers.
