# Modern Clean Theme for Basecart

Modern Clean is a production-grade theme built using `@basecart/theme-sdk`. It features geometric typography, responsive layouts, soft warm cream image cards, interactive size selectors, and optimized checkout CTAs.

## Structure

```
modern/
  ├── manifest.json
  ├── README.md
  ├── changelog.md
  └── theme/
      ├── app/
      ├── sections/
      ├── blocks/
      ├── templates/
      ├── snippets/
      ├── assets/
      ├── styles/
      └── locales/
```

## Features
- Fully responsive across desktop, tablet, and mobile.
- Zero external direct database dependencies.
- Sandboxed SDK data fetching.
