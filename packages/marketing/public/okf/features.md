# Basecart Feature Catalog

## Payments

- Razorpay UPI (GPay, PhonePe, Paytm), cards, netbanking, wallets
- COD with automated verification
- 0% platform transaction fees
- Stripe gateway support on Basic+ plans

## WhatsApp commerce

- Direct WhatsApp checkout links
- Automated order alerts and receipts
- Abandoned-cart recovery via WhatsApp & email

## Shipping & fulfillment

- Shiprocket, Delhivery, DTDC, Speed Post
- Automatic AWB generation and pickup scheduling
- Regional shipping for Kerala & India

## Storefront

- No-code store builder, 2-minute setup
- Custom domain mapping (Plus+)
- Custom storefront themes (Plus+)
- Regional checkout in Malayalam, Tamil, English

## Platform

- Isolated per-tenant databases (D1 SQLite)
- Automated GST invoices & PDF export (Business)
- Developer REST API & webhooks (Business)
- Multi-staff accounts, 5 seats (Business)
- AI description writer & marketing tools (Growth)
